# Réponses aux questions du TP-07
## Q3
@main référence la branche principale du dépôt de l'action, son contenu peut changer à tout moment. 
@v4 référence la version majeure 4 de l'action, ce qui donne une meilleure stabilité et une meilleure prévisibilité.

## Q4
Le badge de créateur vérifié indique que GitHub a vérifié l'identité de l'éditeur ou du créateur selon ses critères mais il ne garantit pas l'absence de vulnérabilités, de comportements malveillants ou de failles dans le code de l'action.

## Q5
Il faut bien : 
- Examiner le code source de l'action, son historique de commits, les éventuelles vulnérabilités et les dépendances utilisées.

- Vérifier sa réputation, son éditeur, les permissions demandées et les accès aux secrets et aux tokens GitHub.
